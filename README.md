# Real-Time Face Mesh Tracker

A computer vision project using Python, OpenCV, and Google MediaPipe that captures 468 3D facial landmarks in real time.

## Features
- Real-time 468-point 3D facial mesh tessellation
- Dynamic bounding box tracking
- CPU-optimized inference with MediaPipe
